# Sprint_6: UI-тестирование с Page Object Model и Allure 

В данном проекте было выполнено задание для практики изученных за спринт основ Page Object Model и интеграции отчётов Allure

* Паттерн Page Object Model 
* Параметризованные тесты 
* Allure-отчеты 
* Тестирование критических пользовательских сценариев

## Тестовый проект для тестирования сервиса "Яндекс.Самокат"

Проект содержит автоматизированные тесты для проверки:
1. **Раздел "Вопросы о важном" (FAQ)**
   - Проверка отображения правильных ответов при клике на каждый вопрос

2. **Оформление заказа**
   - Полный флоу позитивного сценария с двумя точками входа (две кнопки "Заказать" с разных частей страницы)
   - Проверка успешного создания заказа

3. **Редиректы по логотипам**
   - Проверка перехода на главную страницу "Самоката"
   - Проверка открытия Дзена через логотип Яндекса

## Структура проекта

### 1. Тесты
#### `test_faq.py`
- Проверка 8 вопросов с параметризацией
- Верификация текста ответов

#### `test_order_flow.py`
- Два параметризованных сценария заказа:
  - Через верхнюю кнопку "Заказать" с доставкой сегодня
  - Через нижнюю кнопку с доставкой завтра

#### `test_logo_redirects.py`
- Проверка редиректов по логотипам:
  - Самокат → главная страница
  - Яндекс → Дзен 

### 2. Page Objects

#### `base_page.py`
Базовые методы для работы с элементами:
- `click()` - Клик по элементу
- `send_keys()` - Ввод текста
- `scroll_to_element()` - Скролл к элементу
- Методы для работы с вкладками

#### Специализированные страницы:
- `main_page.py` - Главная страница и кнопки заказа
- `order_page.py` - Полный флоу оформления заказа
- `faq_page.py` - Работа с вопросами-ответами

### 3. Данные и конфигурация

#### `data.py`
Структурированные тестовые данные:
- 8 вопросов-ответов для FAQ
- 2 набора данных для заказа
- Ожидаемые URL редиректов

#### `config.py`
Настройки браузера:
```python
BASE_URL = "https://qa-scooter.praktikum-services.ru"
WINDOW_WIDTH = 1366
WINDOW_HEIGHT = 768
MAXIMIZE = True
```
#### `pytest.ini`
Для корректной работы параметризованных тестов с Unicode-символами:
```ini
[pytest]
; Отключает экранирование Unicode в именах тестов
disable_test_id_escaping_and_forfeit_all_rights_to_community_support = True

; Базовые настройки запуска
addopts = 
    --disable-pytest-warnings  ; отключает предупреждения
    -v                         ; подробный вывод
```

### 4. Локаторы

Локаторы сгруппированы по страницам
```python
# Пример из order_page_locators.py
DATE_INPUT = (By.XPATH, "//input[contains(@placeholder, 'Когда привезти самокат')]")
TODAY_DATE = (By.XPATH, "//div[contains(@class, 'react-datepicker__day--today')]")
```


## Как запустить тесты

1. Установить зависимости:
   ```bash
   pip install -r requirements.txt
    ```
2. Запустить тесты с генерацией Allure-отчета: (пример сгенерированного отчёта лежит в `Sprint_6/allure-results`)
    ```bash
    pytest --alluredir=allure-results
   ```
3. Посмотреть отчёт: 
    ```bash
    allure serve allure-results
   ```
